# ZKPrologML Plugin Documentation

## Overview
The **ZKPrologML** plugin provides a ZOS‑compatible interface for context‑aware skill suggestion. It is built as a `cdylib` and can be dynamically loaded by the ZOS plugin bridge.

## Exported Symbols
| Symbol | Description |
|--------|-------------|
| `zos_plugin_name` | Returns the plugin name (`"zkprologml"`). |
| `zos_plugin_init` | Initialization entry point (currently a no‑op). |
| `zos_plugin_shutdown` | Shutdown entry point (currently a no‑op). |
| `zos_plugin_metadata` | Human readable description of the plugin. |
| `zos_plugin_suggest_skills` | Takes a C string `context` and returns a JSON array of skill identifiers relevant to that context. |
| `zos_plugin_free_string` | Frees strings allocated by the plugin (required for any string returned to the caller). |

## Usage Example (Rust)
```rust
use std::ffi::{CString, CStr};
use std::os::raw::c_char;

extern "C" {
    fn zos_plugin_suggest_skills(context: *const c_char) -> *const c_char;
    fn zos_plugin_free_string(s: *mut c_char);
}

fn suggest(context: &str) -> Vec<String> {
    let c_ctx = CString::new(context).unwrap();
    unsafe {
        let raw = zos_plugin_suggest_skills(c_ctx.as_ptr());
        let json = CStr::from_ptr(raw).to_string_lossy().into_owned();
        zos_plugin_free_string(raw as *mut c_char);
        serde_json::from_str(&json).unwrap()
    }
}

let skills = suggest("task-planning");
println!("Suggested skills: {:?}", skills);
```

## Integration
1. Build the plugin:
   ```bash
   cargo build -p zkprologml_plugin --release
   ```
   The shared object will be located at `target/release/libzkprologml_plugin.so`.
2. Register the plugin in `plugins.toml` (already done by the system).
3. Load all plugins via the ZOS bridge:
   ```bash
   cargo run -p forge_infra -- zos_plugin_bridge --load-all-plugins
   ```
4. Query skill suggestions:
   ```bash
   cargo run -p forge_infra -- zos_plugin_bridge --suggest-skills "task-planning"
   ```
