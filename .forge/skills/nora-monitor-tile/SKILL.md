# nora-monitor-tile — Nora Registry Monitor

**Project:** `~/projects/nora/`
**Flake:** `~/projects/nora/flake.nix` (crane + vendorCargoDeps)
**Source mirror:** `/mnt/data1/git/github.com/getnora-io/nora.git`
**Deploy:** `bash ~/projects/nora/deploy.sh deploy`

## Endpoints

```bash
# Health check
curl http://127.0.0.1:4000/health

# Cargo index config (tells cargo where to download)
curl http://127.0.0.1:4000/cargo/index/config.json

# Auto-configure cargo (NEW — 2026-06-16)
curl -s http://127.0.0.1:4000/cargo/config.toml > ~/.cargo/config.toml

# Sparse index root (NEW — was 404, now 200)
curl http://127.0.0.1:4000/cargo/index/

# API status
curl http://127.0.0.1:4000/api/v1/status
```

## Recent Fixes (2026-06-16)

### Cargo sparse index root (RFC 2789)
Previously `GET /cargo/index` returned 404, breaking `cargo build` through nora.
Added handler returning 200 OK. Also handles trailing slash `/cargo/index/`.

### Auto-config endpoint
`GET /cargo/config.toml` returns a ready-to-use `.cargo/config.toml`:

```toml
# Auto-generated by NORA
[source.crates-io]
replace-with = "nora"
[source.nora]
registry = "sparse+http://127.0.0.1:4000/cargo/index/"
[registries.nora]
index = "sparse+http://127.0.0.1:4000/cargo/index/"
```

One-command setup: `curl -s http://127.0.0.1:4000/cargo/config.toml > ~/.cargo/config.toml`

### Nix build (no circular bootstrap)
Nora's own nix build uses crane's `vendorCargoDeps` (downloads from crates.io
directly, not through nora). No `.cargo/config.toml` injection in nora's flake.

## Deploy

```bash
cd ~/projects/nora
bash deploy.sh deploy
# Steps:
#   1. nix flake lock --update-input nora-src
#   2. nix build .#  (crane vendorCargoDeps)
#   3. nix build .#systemConfigs.nora
#   4. sudo <result>/bin/activate + systemctl restart
```
